The purpose of this homelab is to learn networking fundamentals in a virtual environment that will emulate a small business network. This set up will have PFSense with Suricata communicating with Wazuh as the Siem (Suricata running inside PFSense will generate alerts that will be forwarded into Wazuh's dashboard for review). The internal network will have Windows server 2022 set up with Active Directory Domain Services with 2 windows 10 client machines. The client machines and the server will have Wazuh agents. 

Once this is setup and I've documented the process. I'm going to use this homelab to learn everything from the basics to attack and defense. this will be an ongoing project. Any changes will be documented with what has changed, why, and the results of the changes. Any complete rebuilds will be mapped out into a 2.0, 3.0, etc rebuild so when this is being viewed I can go back and review what went right and what went wrong in past builds.
