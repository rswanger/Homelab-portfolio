Priority High User unable to access workstation

**Description**

User Actions: User has tried the passwords they can remember, none of them worked. Does not remember setting this password.

Symptoms: Upon inspection the password screen is for BIOS. ROG flash screen appears does not give bios info loads straight into bios password screen.

Trouble shooting steps:

1        Attempted passwords the user could remember to verify spelling and simple mistakes like caps lock being on. No passwords worked.

2         Attempted Asus standard bios password reset steps. Alt + R, did not result in the correct screen allowing reset.

3        Inspected the case for CMos reset button or pin holes, none located.

4        Opened the case intending to manually reset CMOS. Upon further investigation found that the CMOS is underneath the motherboard requiring almost full tear down. Looking for easier option.

5        Support website said a work around was to remove the battery and boot using AC power only. Resulted in the same password window.

6        As I was about to start removing the motherboard user remembered a password we have not tried. Attempt successful.

7        Allowed pc to complete an update before removing the password from BIOS, per client request.

8        Discussed usage rules for company equipment that can prevent this from happening as well as reminding user that food and drink should not be used while near the laptop.

**Work performed outside of scope of call.**

During troubleshooting I noticed that the outside case was dirty. I cleaned both the outside of the case in order to prevent future troubles as well as cleaned fans and dust off of heat sinks.

**End results**

User is able to access computer and return to their duties. User understands how to best avoid this in the future.
