The CPU (Central Processing Unit) is considered the:

> “brain” of the computer

because it:

- processes instructions
- performs calculations
- executes programs
- coordinates system operations

Very simplified:

- CPU = thinks/processes
- RAM = working memory
- Storage = long-term memory
- GPU = graphics processing
- PSU = power supply


Thermal paste improves:
------------------------------------------
> heat transfer between the CPU and heatsink.

Even though the CPU and heatsink LOOK flat, microscopically they have tiny imperfections and air gaps.

Thermal paste fills those gaps so heat transfers efficiently.

Without good thermal transfer:

- CPUs overheat
- throttling occurs
- shutdowns/crashes can happen
