An SSD (Solid State Drive) has:
----------------------------------------------------
> no moving mechanical parts.

That’s one reason SSDs are:

- faster
- quieter
- more durable
- less prone to physical damage

compared to HDDs, which use:

- spinning magnetic platters
- moving read/write heads

That clicking sound people talk about with dying drives?  
Usually HDDs.


SSDs are dramatically faster than traditional HDDs for:
------------------------------------------------------------------------------------------
- boot times
- application launches
- file access
- overall responsiveness

That’s one reason almost every modern performance-focused system uses SSDs now.

You’ll also eventually learn:

- NVMe SSDs are even faster than SATA SSDs.


SSDs use:
------------------
> flash memory

to store data electronically with no moving parts.

That’s the key difference from HDDs, which use:

- spinning magnetic platters
- mechanical read/write heads

Flash memory is also used in:

- USB drives
- SD cards
- phones
- tablets
